# District-Scale-Waste-to-Energy-Optimization
Uncertainty-aware decision-support model for waste-to-energy in two Ghanaian districts (~305 t/day): literature-based priors, ML methane yield model, Monte Carlo simulation, sensitivity analysis and robust optimization. The districts under focus are Kpone Katamanso Municipal Assembly (KKMA) and Ningo Prampram District Assembly (NPDA)
